# Historische Entwicklungsunterlagen

Dieses Archiv enthält frühere Entwürfe (`specs/`), Arbeitspläne (`plans/`)
und Untersuchungsnotizen (`notes/`). Aussagen, Aufgaben und Codebeispiele
beschreiben ihren damaligen Stand; sie sind keine aktuelle Startanleitung.

Die aktuelle [Dokumentation](../../README.md) und
[Reproduktionsanleitung](../../report/README.md) führen zum Abgabestand.
Verweise auf `CLAUDE.md` betreffen das frühere, heute nur lokal vorhandene
Projektgedächtnis. Die Originalfassung bleibt in der Git-Historie erhalten.
